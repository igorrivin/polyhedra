## Environment recovery and its limits

The [baseline inventory](baseline-environment.json) shows seven missing declared development dependencies: `pytest-cov`, `hypothesis`, `ruff`, `gradio`, `pynauty`, `gymnasium`, and `cma`. Base NumPy/SciPy/mpmath, Torch, pytest, build, plotting and jsonschema packages are installed. The baseline's installed toolkit is an older local 0.3.0 wheel, so source-suite commands explicitly put the canonical package directory on `PYTHONPATH`; the installed-wheel probes clear `PYTHONPATH` and run from `/private/tmp`.

Read-only searches covered the standard uv/pip caches, uv tools/interpreters, Homebrew site-packages, four discovered project virtual environments, and Anaconda environments/package archives. The candidate inventories are [standard locations](offline-dependency-candidates.json), [project environments](project-venv-dependency-candidates.json), [Anaconda metadata](anaconda-dependency-candidates.json), and [Anaconda archive names](anaconda-archive-candidates.json).

Anaconda's `jaxenv` contains compatible pure-Python Hypothesis 6.124.9 and sortedcontainers 2.4.0. Copies in `/private/tmp/polyhedra-release-test-overlay-20261102` enabled the four property tests without altering Anaconda or the baseline environment. The initial directory-only copy omitted Hypothesis's top-level pytest plugin; that unsuccessful setup is retained in `hypothesis-tests-command.json` and its stderr. The subsequent copy follows the installed distribution's RECORD and includes all three top-level helper modules. See [copy hashes](hypothesis-local-copy.json) and [copy repair](hypothesis-local-copy-v2-repair.json). The four passing tests are a separate follow-up, not a new complete-suite count.

Ruff is available in Anaconda, but no package Python source was changed here, so there is no changed-source lint gate to run. Available Gradio installations are 4.x/5.x and do not satisfy the declared `>=6,<7` range. No compatible local Gymnasium, pynauty, cma or pytest-cov installation/archive was found in the examined locations. This is a scoped inventory, not a claim to have searched every byte on the machine.

One normal-sandbox dependency download attempted all seven missing requirements with a fresh target/cache, `--retries 0` and `--timeout 10`. It exited 1 after 0.57 seconds at Gymnasium with `from versions: none` and `No matching distribution found for gymnasium`, downloading nothing. The [exact command](dependency-download-command.json) and [stderr](dependency-download.stderr.txt) are preserved. That output does not establish a defect in Gymnasium or identify whether the index/network caused the empty candidate set. No escalation, browser workaround, repeated network-resolution attempts or existing-cache mutation followed.

Core verification uses two fresh symlink virtual environments with local snapshots of NumPy 2.5.4, SciPy 1.18.1 and mpmath 1.3.0. The sdist environment also has setuptools 84.0.0 solely for the local no-isolation build. These are auditable local dependency copies, **not fresh online resolver installations**. Copy manifests: [core](core-dependency-copy.json), [sdist](sdist-dependency-copy.json). The core-only runtime contains just pip, the toolkit and its three base dependencies. Torch, Gymnasium, Gradio, pynauty, Hypothesis, matplotlib, networkx, plotly and Pillow are absent. The wheel imports the package, geometry, optimization, variational, Rivin Delaunay/holonomy and geometric realization from its installed files.
