# Full-book web author repair, v2

The five required v1 source findings are addressed. This is a source repair and
non-PDF conversion checkpoint, pending independent recheck. It is not a final
edition build, PDF/diagram inspection, browser review, scientific replay, or
publication approval.

This code freeze precedes the subsequent two-file book layout repair for
Figure 8 and the Appendix B page break. The preserved format probe reads the
earlier editorial freeze with SHA-256
`06114dcfc5015ab3289f65eca8b484bd995661e07b5b3699c215e3a2de86f680`.
Its complete source hashes are recorded in its receipt. Later source/PDF
conservation must use the later frozen source and freshly compiled auxiliary
file; this pre-layout probe makes no claim about those later bytes.

1. `source_pages()` now walks and consumes the entire supported chapter-routing
   region, verifies the entry wrapper and bibliography boundaries, and checks
   that every active graph input was consumed. It supports explicit chapter
   `input` and `include` commands, including omitted `.tex` suffixes. Unrouted
   inter-chapter prose/math, unknown or repeated inputs, nested inputs, and
   unexplained wrapper/bibliography content are rejected. The current canonical
   acknowledgment remains in the rendered introduction. Known comments,
   whitespace and print-layout boundaries remain explicitly supported.
2. Ordinary numbered equation environments without canonical labels are
   rejected. Unnumbered starred displays remain supported; a starred display
   cannot acquire a spurious number from a label. The existing strict align-row
   numbering checks remain unchanged.
3. Output and scratch paths reject symlink ancestors before normalization.
   Containment and disjointness checks operate on resolved paths. The exact
   `hop/../checkout/scratch` defect, its output counterpart, normalized overlap,
   and symlink aliases are covered by regressions that stop before build work.
4. The canonical TeX author declaration supplies the visible byline and
   affiliation, as well as author/affiliation HTML metadata. No separate
   maintained byline string was added. Current values are Igor Rivin and
   Department of Mathematics, Temple University. The abstract and canonical
   Codex acknowledgment survive conversion.
5. The externally supplied compilation-reuse CLI option, build parameter and
   receipt loader are removed. Every actual build requires new empty scratch
   space and freshly compiles the frozen book and drawings. The generated
   receipt is output evidence; an in-memory hash recheck protects those fresh
   output bytes while assembling the export. It is not an accepted input
   provenance assertion. Regression checks reject the removed CLI option and
   previously owned scratch space before a compiler can run.
