# Evidence retained and omitted

The [copy manifest](evidence-copy-manifest.json) maps every payload file to exact OUTER source bytes, except the copy manifest and candidate manifest themselves. The candidate manifest includes the copy-manifest identity and excludes its own hash. Independent candidate approval and later postcommit receipts stay outside this payload. All original OUTER evidence remains preserved.

The selection retains exact independent approvals, mathematical source snapshots and correction diffs, initial required findings and their resolution, claim/label/source coverage, finite contracts, source/runtime freezes, actual author and clean-source results, independent oracle evidence, executed-command records, accepted checkpoint tools and their targeted binding reviews. The geodesic author scratch script/result are included because the committed ledgers reference them explicitly.

One full-v1 author report is retained at the independent oracle's required relative input path. Duplicate v1/v2 reviewer replay results are omitted; their identities, execution receipts, equality audits and acceptance remain. Partial four-group reports cannot satisfy the final fourteen-group admission gate and are omitted. Repeated reviewer subject trees, redundant full source copies, draft generators, temporary Git repositories, caches and bytecode are omitted.

The baseline Git commit, full inventory, extraction manifest/diff and eleven changed/new extracted files reconstruct the original structural stage; duplicate expanded manuscript bodies and the other 25 unchanged inputs are omitted. The full normal structural-review inventory is retained; the duplicated optimized inventory remains OUTER, with its identity and optimized acceptance/check receipts retained. Intermediate 49-test author checkpoint logs are omitted while the final 50-test v2 and 55-test v3 results, initial failures and independent repairs remain.

The exact reviewed PDF is retained once at its canonical artifact path. Its actual input/build/visual records, log, recorder, aux data, and selected critical page images are retained. The selected final page images show the repaired Hessian (102), corrected source locators (103 and 107), the positive-boundary question (186), convention tables (191–192), and bibliography pin (195). Other page images and contact sheets remain OUTER; their hashes and actual review coverage remain in the render/visual manifests, and the exact PDF supports later rendering. The preliminary PDF is omitted; its P01 finding, original page-100 image and once-only operation marker remain.

The source checkpoint's complete command ledger is retained. Empty command output streams and redundant per-path `git show` dumps remain OUTER; the ledger records their exact identities, and the committed source provides those blob bytes. Nonempty mutation/status/integrity evidence is retained. Historical scripts and machine records can still name original OUTER paths; those provenance references do not imply publication of every temporary directory.

Ignored raw extensions such as `.log`, `.fls` and `.aux` are renamed to `.log.txt`, `.fls.txt` and `.aux.txt`, preserving exact bytes. The copy manifest records both names. Git ignore rules and the exact visible-untracked-path gate are unchanged.

The [bounded whitespace record](artifact-whitespace-exceptions.json) lists every copied verbatim evidence path, identity and exact default-check diagnostic requiring an artifact-only exception. It permits no broad directory exemption or source normalization. Authored reader documents and canonical source pass default whitespace checks. The later candidate review must approve these exact evidence bytes before artifact staging.

Frozen Markdown source snapshots from before/after directories are stored as `.md.txt` so their original repository-relative link syntax remains literal source evidence. Their bytes are unchanged. The copy manifest records the original names for isolated restoration; active reader documents use curated links.
