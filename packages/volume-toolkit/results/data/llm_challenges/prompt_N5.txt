**Your task:** Produce 5 points on the unit 3-sphere S^3 (i.e., each point has unit norm in R^4) whose convex hull has exactly this combinatorial type — the same face lattice up to relabeling of vertices.

**Output format:** Return ONLY a JSON object with a single key "points" containing a list of 5 points, each a list of 4 floats. Example format:
